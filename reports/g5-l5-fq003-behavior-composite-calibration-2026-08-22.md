## Exact implementation boundary

The implementation adds four bounded capabilities:

1. A source parser/IR compiler reads the hash-bound FFDec AVM1 script export and swfmill display-list/font export. It derives only assignments and states that are explicitly present in those inputs. Unknown or changed assignments fail closed.
2. The shared Canvas factory accepts an optional, versioned behavior-composite contract. Ordinary source-static candidates continue through the ordinary `render` path; only an exact contract/state pair may call `renderComposite`.
3. The FQ003 builder deterministically expands the source-derived IR into an exact state allowlist and regenerates only the FQ003 adapter specification, runtime, manifest, IR, and timeline hash bindings.
4. The My Lesson product bridge maps its maintained quiz state to the exact source-composite state. The mapping rejects missing review responses, wrong contract IDs, unknown states, unsupported frames, invalid text/glyph/color values, and mismatched render identity.

The ignored `work/` copies of the two raw FFDec Canvas exports are hash-bound staging inputs only. They are not canonical-source promotion, Git evidence, release assets, or acceptance evidence. `npm run verify:sources` confirms the canonical frozen source tree remains unchanged and read-only.

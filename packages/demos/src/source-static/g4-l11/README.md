# G4 L11 source-static facts

This directory holds immutable, source-bound structural audit projections for
the fourteen audited G4 L11 members listed in the portability test.  They are
not animation modules: no file in this directory exports a default renderer or
`getFrameState`, and this directory is intentionally outside the runtime
timeline and registry import surfaces.

The data may describe source behavior, timelines, audio obligations, and
blocked dependencies, but it neither executes ActionScript nor supplies a
JavaScript candidate, original-runtime evidence, audio acceptance, human or
owner approval, strict completion, or lesson publication authority.  The two
exact L11 Key Terms XML paths remain `BLOCKED_NO_EXACT_SOURCE_BYTES`; grade-wide
XML files are retrieval leads only and are not replacements.

`packages/demos/src/source-domain-specifications/g4-l11/course-g04-l11-in-010.ts`
is deliberately excluded from this directory. It has a separate prospective
source-domain inspection specification and remains outside this fourteen-member
source-static portability set.

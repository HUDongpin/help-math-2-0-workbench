      Four rules the placement encodes

      These are the decisions that make a tutor feel built-in rather than bolted-on. Each is visible in the prototype above.

      1

      Nova speaking pauses the lesson speaking

      Two voices at once is unusable for a nine-year-old, and worse for the Spanish learner this course serves. Opening Nova pauses narration and says so on the plane; closing it resumes at the same frame. This is the one rule that cannot be optional.

      2

      Context is attached, never typed

      A child should not have to explain where they are. Nova opens already holding the animation id, section, page ordinal and a snapshot of the current frame — shown honestly as a “Nova can see” chip, so nothing about the data flow is hidden from a school buyer.

      3

      Voice outranks text

      A Grade 4 pupil types slower than they think. The microphone is the biggest control in every placement and text is the fallback, which inverts the usual chatbot hierarchy and matches how this age group actually asks for help.

      4

      Photos flow both ways

      The camera sends the child’s paper working up; the player sends the current frame down. The second direction is free — the canvas is already there — and it is what lets Nova say “look at where you put Ricky” instead of asking what the question was.

      What HELP Math has to supply

      Nova needs three things from the player. All three already exist in the codebase.

      1

      A page context object

      apps/web/lib/g4-l3-lesson-navigation.ts already carries animationId, sectionCode, globalPageOrdinal and both title languages per page. That record is the tutor’s context payload as-is — no new data model.

      2

      Transport control the tutor can call

      The shell already owns onPausedChange and the narration state. Nova needs to borrow it on open and return it on close, which is a prop, not an architecture.

      3

      A frame snapshot

      The page renderer draws into a real canvas in loaded-swf-host-canvas.tsx, so the current frame is one toDataURL() away. Worth doing after the scale-aware renderer lands, so the image Nova receives is the sharp one.

      4

      One launcher, suppressed where it does not belong

      This mirrors what MAIS already does — its own stylesheet hides button[aria-label*="AI Tutor"] inside the practice arena and the home hero. Same instinct here: no floating launcher over the lesson plane; the entry point lives in the control bar, and Classroom replaces it with the band.

      Public pages on mais.ac name Nova Tutor but keep the product behind sign-in, so this design works from the capability set you gave — audio, text, images — plus the integration pattern the site does expose. Anything you can share about the real conversation UI would sharpen the panel further.

The same eight steps, in every lesson

A shape students can learn once and rely on 29 times

Every lesson in the archive — all 29, without exception — runs the same eight sections in the same order, with the same bilingual names. That is not a design convention we invented; it is how the program was authored. The interface makes it visible instead of hiding it behind a Next button.

Section names come straight from the lesson source files. catalog/lessons.json — 29 of 29 lessons share this sequence.

Nova Tutor

Help that already knows where you are

Nova opens holding the page you're on, the section you're in, and a picture of your screen. A fourth-grader should never have to type their way back to the question.

On Try It, Practice Test and Final Quiz, Nova scaffolds and never answers — enforced in the page context, not in prompt wording.

Adaptive path

BKT chooses what's next. Nova chooses how to say it.

A Bayesian knowledge-tracing estimate per skill decides which lesson section a student sees next. The language model handles explanation, rephrasing, and the student's own questions — it never sets the sequence.

Design notes

Why this interface looks the way it does

Every structural decision below is drawn from what is actually in the repository, not from a generic ed-tech pattern. This screen exists so the reasoning can be argued with.

The navigation question, answered with the catalog

A persistent navigation area is right here, and the reason is stronger than usual: all 29 lessons share one identical eight-section sequence. A student learns the shape once and it holds for every lesson in the program.

CodeEnglishSpanishWhat it isPages, G4 L3

Source: catalog/lessons.json — 1 distinct section sequence across 29 lessons. Page titles and Spanish labels: apps/web/lib/g4-l3-lesson-navigation.ts.

Three reasons a persistent page strip fails here

Volume. 39 pages in this lesson, 54 in Grade 5 Lesson 4, 80 in Grade 4 Lesson 1, 93 in Grade 3 Lesson 9. A strip of 93 items has no legible resting state at any width.

Imbalance. Learn It carries 21 of Grade 5 Lesson 4's 54 pages while Play It carries exactly 1 — in every lesson in the catalogue. Size the stops proportionally and one section takes 39% of the rail while another takes 2%. The spine uses equal-width stops with the page count written on them instead.

Repetition. Five consecutive pages in this lesson are titled Numbers on the Number Line; five more are titled 4 - Step Plan. Titles alone cannot express position, which is why every page reference in the course map carries its section code and ordinal — IN03, not "page 3".

The tradeoff, and its mitigation. A section spine gives orientation — "I am in Learn It, 4 of 8" — at the cost of within-section wayfinding: a learner nine pages into a 21-page section cannot jump to page 14 from the spine. So the fine-grained view stays, as an on-demand overlay that never auto-opens: every page with its ordinal, a ✓ when reviewed, and an explicit unavailable state where no renderer is registered. Persistent navigation is coarse and cheap; on-demand is fine-grained and complete.

Two language controls, not one

The learner's lesson language and the teacher's interface language are separate settings, because they answer to different people. A bilingual teacher may work in Spanish while their class reads the lesson in English, or the reverse, and slaving one to the other forces a choice neither person should have to make.

Lesson language — governs lesson content, the section spine, vocabulary, and every student surface. It is the setting the codebase already implements as locale routing, and it is where the no-invented-Spanish discipline binds: an English fallback is shown and marked, never translated.

Teacher interface language — governs the class board and lesson prep only. It never changes what a student sees and it never reaches the catalog. Authored vocabulary stays paired in both languages regardless, because a sheltered lesson plan needs both on the board.

These design notes stay in English: this screen is a rationale document for the project, not a product surface.

The design system

Colour

Extends the existing :root tokens in globals.css rather than replacing them. Nova's indigo and cyan are sampled from the source artwork's footer media pod, which keeps the tutor visually distinct from action blue, progress amber, and mastery mint.

The hard-offset edge is the project's own, not an invention. globals.css authors box-shadow: Npx Npx 0 var(--ink) at seven offsets against 2px ink borders and asymmetric radii; the soft --shadow token is used three times in 9,254 lines and --radius is used none. Learner surfaces take that edge. Teacher data surfaces stay on hairlines — a mastery grid of 24 students needs calm, not 24 competing borders.

Type

A rounded geometric display face echoes the Bauhaus-family type used inside the original lesson artwork, without embedding a licensed font. Body type stays on the project's own Nunito Sans stack; a tabular mono carries every number that has to line up.

The one motif

Position is always a ruled line with ticks — lesson progress, section completion, and mastery probability all use it. The curriculum's own core object is the number line and its structure is a linear run of named stops, so one visual grammar covers all three without a student having to learn a second one.

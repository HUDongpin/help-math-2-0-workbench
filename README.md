# HELP Math Flash to JavaScript

This repository is the migration workbench and Next.js application for the
evidence-led recovery of the owner-provided HELP Math Flash library. Read
`AGENTS.md`, then invoke `$flash-to-js` for every FLA/SWF migration.

No animation is considered faithfully migrated merely because it runs in a
browser. A public-library item must pass the strict migration validator,
full-frame/scenario comparison, language and audio review, product QA, human
visual review, and owner acceptance.

## Current evidence-backed status

- 7,919 legacy files are frozen read-only: 2,779,928,841 bytes.
- 1,894 SWF placements map to 1,873 distinct SWF binaries; 21 duplicate
  placements retain separate IDs and source provenance.
- The SWFs contain 32,149 root-timeline frames, all at 12 FPS.
- 1,181 SWFs have a paired FLA, 713 are SWF-only, and 217 additional items are
  FLA-only.
- All 1,398 FLA files use the legacy OLE compound-binary container; none is an
  unpacked modern XFL document.
- The generated queue contains 77 batches, each with at most 25 canonical
  assets.
- Sixteen cross-type pilot workspaces exist at the `preserved` gate.
- Strict migrations complete: **0**.

The catalog also records 591 missing course-SWF references and 317 missing
key-term-SWF references. The latter corrects the earlier estimate of 316: both
key-term XML files use a whitespace variant of `ExFileName` for the missing
`Cubed_root.swf`. Missing sources and FLA-only items are reported, never guessed.

Machine-readable evidence lives in `catalog/`, including the source manifest,
placement catalog, canonical assets, duplicate groups, missing and unreferenced
sources, audio associations, lessons, and batch queues. Exact workstation tool
versions are recorded in `catalog/toolchain.json`.

`catalog/completion-ledger.json` is the fail-closed publication authority. It is
generated by running the strict validator against every migration and records
the validator version/hash plus each admitted manifest hash. A handwritten
`status: complete` is insufficient. The current ledger has zero admitted
entries and 16 `preserved` diagnostics.

## Preserved sources

The canonical local archive is:

```text
source-assets/flash/HELP MATH_ORIGINAL FILES/
```

The top-level `HELP MATH_ORIGINAL FILES` path is a compatibility symbolic link.
Neither path belongs in ordinary Git or a web deployment. The freeze manifest
is `catalog/source-manifest.sha256`; its own SHA-256 is
`a9625fb4a99e026fea09e4a1929edc2fa9d47ccf6cdbca7de4ba9ca75adf211e`.

Verify the archive without modifying it:

```bash
npm run verify:sources
```

See `docs/ARCHIVE.md` for the separate private-archive boundary and recovery
procedure.

## Bootstrap and verify

Use Node.js 24 LTS, as recorded in `.nvmrc`:

```bash
npm ci
npx playwright install chromium
npm run doctor
npm run verify:workbench
npm run ledger:check
npm test
npm run verify
```

`doctor` treats Adobe Animate as an optional capability, but any pilot whose
binary FLA needs authoring-library, timeline, script, or font inspection cannot
clear that evidence gate until an authorized Animate workstation is available.
See `docs/TOOLING.md`.

## Build or run the applications

The product application is the isolated `@helpmath/web` workspace:

```bash
npm run dev
npm run build
```

English is served without a URL prefix and every public route has a Spanish
counterpart under `/es`:

- `/library` — fail-closed public catalog; only strict ledger entries appear.
- `/courses/3/1` — grade/lesson course sequence.
- `/animations/[animationId]` — unified modern animation player.
- `/migration-status` — source, alias, missing-source, and progress ledger.
- `/reference/[animationId]` — local-development SWF/Ruffle forensic route;
  disabled in production.

The reviewed preview routes are `/demos`, `/demos/conversion-1-2`, and
`/demos/conversion-1-4`; none is represented as a completed fidelity migration.
The application consumes the reviewed completion ledger and dynamic registry
from `catalog/` and `packages/demos/`; see `docs/DEPLOYMENT.md` for the required
monorepo deployment boundary.

The earlier two-animation workbench remains available for regression work:

```bash
npm run dev:workbench
npm run build:workbench
```

`Conversion_1_2` and `Conversion_1_4` are runnable conditional-review previews.
They are not strict migrations and are not presented as production-complete.

## Rebuild the intake catalog

The catalog generator streams hashes, parses FWS/CWS headers, pairs FLA/SWF,
tolerantly reads the original course/key-term XML, resolves bilingual audio,
and produces stable placement and canonical IDs:

```bash
npm run catalog:build
```

The command fails when the approved archive totals or the universal 12 FPS
contract do not match. It never writes inside the source archive.

## Scaffold migration work

Create or verify the approved pilot set and import only catalog-backed intake
evidence:

```bash
npm run scaffold:pilots
npm run sync:migrations
npm run audit:pilots
npm run sync:machine-audits
```

The machine audit records FFDec/swfmill headers, tags, scripts, ActionScript
signals, external-call candidates, and source/output hashes. It remains
`partial` and never advances status: FLA authoring inspection, authoritative
runtime traversal, audio timing, and visual baselines are separate gates.

Preview a production batch without writing:

```bash
npm run scaffold:batch -- --batch batch-001 --dry-run
```

Do not create later production batches until all 16 pilots satisfy the strict
exit gate. For an individual animation:

```bash
npm run scaffold:migration -- <animation-id> --fla <path> --swf <path>
node skills/flash-to-js/scripts/validate_migration.mjs \
  migrations/<animation-id> --allow-draft
```

`--allow-draft` verifies workspace shape and intake evidence only. Omit it only
after the audit, baseline, implementation, full-frame evidence, reviews, and
acceptance checklist are genuinely complete.

## Deterministic capture and validation

Every modern renderer must implement `?frame=`, `?scenario=`, `?lang=en|es`,
and `?seed=`, and report the exact one-indexed frame through
`data-flash-frame`.

```bash
npm run capture:keyframes -- --help
npm run compare:frames -- --help
node skills/flash-to-js/scripts/validate_migration.mjs migrations/<animation-id>
```

Raw full-frame archives belong under the ignored `artifacts/full-frame/` root.
Migration workspaces retain their archive path and digest, all metrics, key
teaching frames, every failed/outlier frame, and diff evidence. Ruffle is a
versioned forensic reference only; it is never the production renderer.
